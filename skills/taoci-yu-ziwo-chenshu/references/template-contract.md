# 模板约定

公开包不附带 DOCX、PDF、简历、照片或真实名录。用户提供自己的套磁信 DOCX、自我陈述 DOCX 及与该自述对应的基准 PDF，并在私有配置中填写路径。基准 DOCX 与 PDF 抽取文字须一致，首次使用仍需逐页核对版式。

当前脚本适用的模板结构：

| 文件 | 可编辑位置 | 配置与处理 |
| --- | --- | --- |
| 套磁信 | 红色导师姓名 | 完整文字等于 `baseline_advisor`，替换为当次导师姓名 |
| 套磁信 | 红色研究方向 | 完整文字等于 `baseline_direction`，替换为已核验方向 |
| 自我陈述 | 唯一的“科研兴趣：”段落 | 保留标题，替换标题后的整段文字 |
| 自我陈述 | “自我评价：”后的开头（可选） | `statement_opening_deletions` 配置精确字符串；匹配时删除该字符串及紧随的一个逗号或句号；默认空数组，不删除 |

删除配置非空但没有匹配项时拒绝构建，避免误用变化后的模板。精确删除范围内的文字均视为该删除配置已授权，其余红色字段仍须映射。科研兴趣段落以外的红字仅支持上述导师名与方向映射；未知红字拒绝。不要把无关红字默认视为导师名。

以 `baseline_advisor=模板导师`、`baseline_direction=示例研究方向` 为例，两处红字须完整等于这两个值，可拆在多个相邻 run 中。真实模板若用其他标记，应更新私有配置，不要保留别人的导师姓名或套用别人的个人文本。

脚本保持原 ZIP 部件、图像、关系、样式及非编辑 XML 部件的字节。只序列化发生文字编辑的 story XML；跨 run 替换沿用第一处受影响文字的格式。`--black` 会把识别出的红色 run 设为黑色。修订、复杂域、内容控件或嵌套特殊结构须单独验证，不默认兼容。

自述最终 PDF 页数须等于用户指定的基准 PDF。该约束来自模板容量，不固定为某个历史页数。文案过长时先压缩文案，不为塞入内容随意缩小字体、页边距或删除图片。脚本不实现模板元数据匿名化；如以后公开用户自己的文档，应另行检查属性、批注、修订、隐藏文字、嵌入对象和图片信息。
