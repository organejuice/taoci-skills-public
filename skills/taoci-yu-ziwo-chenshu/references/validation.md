# 验证说明

从该 skill 目录运行：

```powershell
python -B -m unittest discover -s tests -v
python -B scripts/workflow.py --help
```

测试仅使用运行时生成的合成名录、文档、图片与 PDF，执行后清理临时目录，不读取真实材料或执行邮件发送。`python-docx` 与 `reportlab` 仅为合成测试依赖；运行脚本仍需要 `lxml`、`openpyxl`、`pdfplumber`。测试覆盖联合身份匹配、同名消歧、编号保持、红字和跨 run 替换、未授权字段拒绝、源件与非编辑包部件保持、证据结构、逐页回执及哈希绑定、原模板保护与无覆盖发布。

合成验收测试对 PDF 抽取进行隔离，以验证文件绑定与发布门控；它们不能证明 Word/外部渲染、真实模板分页、字体、论文证据或申请文案质量合格。真实使用前须用自己的模板在隔离工作目录完成 `inspect → build → render → qa → publish` 并逐页检查，正式输出目录不作为测试目标。

公开版未附带原项目运行历史、截图、个人文书、真实模板哈希或验收回执。公开包根目录的隐私检查报告说明本次导出的检查范围；不要据此声称未来填入的私人数据也可以公开。
